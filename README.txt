KENGA PROWASH SERVICES WEBSITE
==============================

Included:
- index.html: website content
- styles.css: responsive design
- script.js: mobile menu, year and enquiry email preparation

HOW TO PREVIEW
1. Extract this ZIP file.
2. Open index.html in a web browser.
3. Internet access is needed for the online photographs and Google Fonts.

IMPORTANT BEFORE PUBLISHING
1. Your contact email and phone number have been added. The enquiry form is set to kengaprowashservice@gmail.com.
2. Your contact details are set to kengaprowashservice@gmail.com and +675 82922854. Initial service location is Port Moresby, Papua New Guinea.
3. Add your confirmed service area, business registration details (once registered), and real project photos.
4. The services are described as planned services; only advertise services you are ready and able to provide.
5. The enquiry form opens the visitor's email app. It does not store submissions or send them to a database.

FREE PUBLISHING OPTION: GITHUB PAGES
1. Create a free account at https://github.com/
2. Create a new public repository named kenga-prowash-website.
3. Upload index.html, styles.css and script.js to the repository's main/root folder.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose branch main and folder /(root), then Save.
7. Wait for GitHub Pages to publish and use the website URL shown in Settings > Pages.

You can also use Netlify Drop at https://app.netlify.com/drop by dragging the extracted website folder onto the page. Check its current free-plan terms before publishing.
